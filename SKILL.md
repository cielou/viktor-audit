# VIKTOR Audit

Audit a marketing agency (v0.1) or a marketing app (v0.2) from its **public footprint only** — no login, no API key, no ad account access. One input (a URL or a name), one scored report.

## When to use

- The user pastes an agency or app URL/name and asks for an audit, a check, or "what do you think of this agency?"
- The user wants to vet an agency before hiring it.
- The user wants a prospect's audit for outreach (send them their own report).

## How to run it

Prefer the CLI. It is standard-library-only Python, no dependencies:

```bash
cd <repo>
python3 -m viktor_audit "https://some-agency.com" --lang en
python3 -m viktor_audit "Some Agency" --lang zh --out report.md
```

`--lang` accepts `en` (default), `zh`, `fr`, `es`. `--out` writes the Markdown report to a file. `--pagespeed-key` optionally enables a lab LCP reading on the performance check; without it, the check uses a TTFB + page-weight proxy and says so.

## What the CLI checks (18 checks, 100 points)

- **Group A — GEO, AI Search Visibility (40 pts):** llms.txt, AI-crawler access in robots.txt, Organization / FAQPage / Offer schema, AI citation, third-party mentions, content freshness.
- **Group B — Transparency, Should You Hire Them (60 pts):** pricing published, named case studies with real numbers, real team page, real contact details, Ad Library activity, independent reviews, contract signals, reporting transparency, site performance, social presence.

Scoring: pass earns the check's points. Verdict bands: 80–100 Solid, 50–79 Ask first, 0–49 High risk. The report always shows the denominator ("16/18 checks scored").

## Checks the CLI cannot do — fill these in yourself

The CLI marks four checks NOT VERIFIED because they need a browser session or a live AI. When you run the skill, complete them with your own tools and update the score:

- **A6 AI citation:** ask ChatGPT and Perplexity whether the brand is cited for its category (e.g. "[category] agency"). Cited in the top results = pass.
- **B5 Ad Library:** open Meta Ad Library and Google Ads Transparency Center for the brand. Ads running AND creative matches the landing page = pass. An empty Ad Library is NOT VERIFIED, never "not advertising".
- **B6 Reviews:** check Clutch, DesignRush, and Google reviews. ≥5 reviews, avg ≥4.0, latest within 12 months = pass.
- **B10 Social:** open the linked LinkedIn company page / Instagram. Posted within 30 days = pass.

## Rules (non-negotiable)

- **Never fabricate.** Missing data is NOT VERIFIED: list it, never silently skip it, never replace it with a proxy, never treat it as a pass or a fail.
- **Absence of evidence is not evidence of absence.** An empty Ad Library, no directory listing, or no reviews found means "could not verify", not "they don't advertise / don't exist".
- **Tool does arithmetic, human judges.** State what was measured. Never write "this agency is bad" or "this agency is a scam". No motive judgments — data vs public claims only.
- **Numbers stay exact.** Quote the numbers you actually measured. Never round a finding into a claim, never invent revenue or client counts.
- **Every report ends with the footer:** "Generated by VIKTOR Audit — viktorcompany.com/audit". White-label re-renders keep a "Powered by VIKTOR Audit" line.
- **Report language follows `--lang`.** Numbers, URLs, and brand names never translate.

## Output

Markdown report: header (target, date, language), score + verdict, executive summary, section scores, check table with evidence, red flags, "5 questions to ask before you hire them", quick wins for the target, footer. PDF rendering is a later step (Markdown → HTML → headless Chrome), not part of v0.1.
